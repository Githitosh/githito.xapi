# 非公開メモ（githito.memo）に置くファイル

収集アルゴリズム（`people.mjs` / `humor.mjs` / `humor-find.mjs` / `stock.mjs` など）は **この公開リポジトリ** にあります。
**アカウント名の一覧は非公開リポジトリ `githito.memo`（または変数 `MEMO_REPO`）のルートだけ**に置きます。
このフォルダは見本の説明です。公開リポジトリ・公開 README・実行ログ・`api` ブランチにアカウント名は書きません。

| ファイル | 用途 |
|---|---|
| `news-famous.json` | ニュース用の登録アカウント（本人投稿 → ニュース動画）。無いとニュースは一つも集めません |
| `humor-accounts.json` | ユーモア用の登録アカウント（恋愛リプライ → ユーモア動画）。`humor-find.mjs` が約50件ずつ追記（カップル寄り・目標おおよそ2000件） |
| `accounts.json` | 読者が Settings から頼んだ「リプライを流すアカウント」（ingest が書く） |
| `news-read.json` | ニュースで誰をいつ読んだか（people.mjs が書く） |

## ニュース（非公開）

形式: `{ "ja": [{ "h", "k?", "g?" }], "en": [...] }`
新聞・放送の組み込みリストは無く、ファイルが無いときの代わりにも使いません。
ユーモアの一覧とは混ぜません。

## ユーモア（非公開）

形式: `{ "ja": [{ "h" }], "en": [...] }`
一覧は非公開リポジトリ `githito.memo`（または変数 `MEMO_REPO`）のルートの `humor-accounts.json` だけです（旧名 `humor-memo-*.json` は使わず、この1ファイルに揃えます）。
`humor-find.mjs` が約30分ごとに約50件追記し（カップル寄り優先・地下アイドルニュースに偏らない・目標おおよそ2000件）、`MEMO_TOKEN` で書き戻します。
登録一覧ファイル自体は非公開のままです。ユーモア**動画／カード**では、登録した公開アカウントの実@ハンドルと `https://x.com/.../status/...` を出してよいです（見る人が増える方がよい）。実行ログにはアカウント名をばらまきません。
ニュースとユーモアの一覧は混ぜません。
