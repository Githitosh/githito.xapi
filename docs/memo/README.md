# 非公開メモ（githito.memo）に置くファイル

収集アルゴリズム（`people.mjs` / `humor.mjs` / `humor-find.mjs` / `stock.mjs` など）は **この公開リポジトリ** にあります。
**アカウント名の一覧は非公開リポジトリ `githito.memo`（または変数 `MEMO_REPO`）のルートだけ**に置きます。
このフォルダは見本の説明です。公開リポジトリ・公開 README・実行ログ・`api` ブランチにアカウント名は書きません。

| ファイル | 用途 |
|---|---|
| `news-famous.json` | ニュース用の登録アカウント（本人投稿 → ニュース動画）。無いとニュースは一つも集めません |
| `humor-accounts.json` | ユーモア用の登録アカウント（恋愛リプライ → ユーモア動画）。`humor-find.mjs` が約20件ずつ追記 |
| `accounts.json` | 読者が Settings から頼んだ「リプライを流すアカウント」（ingest が書く） |
| `news-read.json` | ニュースで誰をいつ読んだか（people.mjs が書く） |

## ニュース（非公開）

形式: `{ "ja": [{ "h", "k?", "g?" }], "en": [...] }`
新聞・放送の組み込みリストは無く、ファイルが無いときの代わりにも使いません。
ユーモアの一覧とは混ぜません。

## ユーモア（非公開）

形式: `{ "ja": [{ "h" }], "en": [...] }`
`MEMO_TOKEN` で読み書きします。
