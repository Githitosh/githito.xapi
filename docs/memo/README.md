# 非公開メモ（githito.memo）に置くファイル

収集は **ここに書いたアカウントだけ** から動画用の投稿を取ります。
ユーモアは、30分ごとの実行で `humor-find.mjs` が恋愛リプライ系のアカウントを約10件ずつ `humor-accounts.json` に追記し、その記録から発言を取って動画にします。
このフォルダは見本です。中身を非公開リポジトリ `githito.memo`（または変数 `MEMO_REPO`）のルートに置きます。
アカウント名は公開リポジトリの README・実行ログには書きません。

| ファイル | 用途 |
|---|---|
| `news-famous.json` | ニュース用の登録アカウント（本人投稿 → ニュース動画）。無いと `people-ja.json` が空のままになります |
| `humor-accounts.json` | ユーモア用の登録アカウント（恋愛リプライ → ユーモア動画）。やりとりの双方を載せる。`ja` / `en` 各約100件＋実行ごとの追記 |
| `accounts.json` | 読者が Settings から頼んだ「リプライを流すアカウント」（最大8・ingest が書く） |
| `news-read.json` | ニュースで誰をいつ読んだか（people.mjs が書く） |

ニュースとユーモアの一覧は混ぜません。有名人をユーモア側に入れないでください。
